全球動力科技股份有限公司（以下稱「本公司」）經營 Big x Reality 官方網站（以下稱「本網站」）。本公司依《個人資料保護法》（以下稱「個資法」）及相關法令，說明本網站蒐集、處理及利用個人資料的方式。本政策僅適用於本網站；經由本網站連結前往的其他網站，適用該網站自己的隱私權政策。

## 一、網站瀏覽與偏好設定

本網站是靜態網站，頁面不設會員帳號，目前未載入 Google Analytics 或廣告追蹤程式。網站會使用瀏覽器的 localStorage 儲存「暫停動畫」偏好（bxr-motion），用途僅為在不同頁面保留顯示偏好，不包含詢問表單內容，也不會作為廣告追蹤識別碼傳送。此設定可透過恢復動畫或清除瀏覽器網站資料移除。詢問表單及電子郵件的資料處理方式分別見第二節與第三節，主機服務的存取紀錄見第五節。

## 二、線上詢問表單

本網站的產品、解決方案及「聯絡 BXR」頁面提供線上詢問表單。表單底部有「同意並送出」與「不同意」兩個按鈕：按下「同意並送出」即表示您同意本政策，表單才會送出；按下「不同意」或未送出前，填寫的內容不會傳送給本公司，也不會保存在您的瀏覽器。

**蒐集的資料**

- 您填寫的資料：姓名、公司／單位、Email（以上必填）；職稱、國家／地區、電話（以上選填）；洽詢項目、感興趣的產品與解決方案（可複選），以及需求說明。
- 送出時一併記錄：送出時間、送出表單的頁面路徑與語言、系統產生的詢問編號、您同意的隱私權政策版本。本網站的接收程式不記錄您的 IP 位址。

**處理方式**：表單由您的瀏覽器直接傳送至本公司以 Google Apps Script 建立的接收程式，資料儲存在本公司的 Google 試算表，僅本公司授權人員可以存取。Google 雲端服務由 Google LLC（位於美國）提供，資料可能存放在 Google 資料中心所在的國家或地區；送出時您的瀏覽器會連線至 Google 的伺服器（script.google.com、script.googleusercontent.com），Google 可能依其隱私權政策記錄連線資訊。若啟用新詢問的 Email 通知，詢問內容亦會寄送至本公司指定的收件信箱。

**蒐集目的**：回覆您的詢問、提供產品展示與資料、洽談合作及後續客戶服務（特定目的：〇九〇 消費者、客戶管理與服務）。

**利用期間**：於回覆詢問、提供後續服務及履行法定義務所需的期間內保存；蒐集目的消失或保存期間屆滿後，依適用法令刪除、停止利用或去識別化處理。

**利用地區**：中華民國境內，以及 Google 雲端服務的資料處理所在地區。

**利用對象與方式**：由本公司業務及客服人員以電子郵件、電話等方式回覆及聯繫；除依法令要求或經您同意外，不提供給第三人。

必填欄位未填寫或您不同意本政策時，表單不會送出；您仍可改用下一節的電子郵件方式聯絡本公司。

## 三、您主動以電子郵件聯絡本公司

本網站的「聯絡 BXR」頁面與頁尾提供電子郵件連結（service@gptt.com.tw）。點選後會開啟您裝置上的郵件軟體，並預先帶入主旨與下列欄位提示：姓名、公司／單位、職稱、國家、電話、需求說明。郵件是否寄出、填寫哪些內容，由您自行決定；本網站本身不會接收或儲存這些內容。

您寄出郵件後，本公司會取得：

- 您的電子郵件地址，以及郵件中您自行提供的資料（例如姓名、公司／單位、職稱、國家、電話、需求說明）。
- 您的郵件服務自動附帶的郵件標頭資訊。

**蒐集目的**：回覆您的詢問、提供產品展示與資料、洽談合作及後續客戶服務（特定目的：〇九〇 消費者、客戶管理與服務）。

**利用期間**：於回覆詢問、提供後續服務及履行法定義務所需的期間內保存；蒐集目的消失或保存期間屆滿後，依適用法令刪除、停止利用或去識別化處理。

**利用地區**：中華民國境內，以及本公司電子郵件服務供應商的資料處理所在地區。

**利用對象與方式**：由本公司業務及客服人員以電子郵件、電話等方式回覆及聯繫；除依法令要求或經您同意外，不提供給第三人。

您可以不提供上述資料，但本公司可能無法回覆您的詢問或提供您需要的資料。

## 四、站內搜尋

本網站的站內搜尋使用 Pagefind。搜尋索引在網站建置時產生並與網站一起發布，搜尋是在您的瀏覽器內比對該索引完成，您輸入的關鍵字不會傳送給本公司或其他搜尋服務。為了方便重新整理或分享，關鍵字會顯示在該頁網址中（例如 `?q=關鍵字`）。

## 五、網站主機與存取紀錄

本網站託管於 GitHub Pages（GitHub, Inc.，位於美國）。當您瀏覽本網站時，您的瀏覽器會直接向 GitHub 的伺服器要求網頁，GitHub 可能為維護服務安全與運作而記錄您的 IP 位址等存取資訊。這些紀錄由 GitHub 依其隱私權聲明處理，相關資訊可參閱 [GitHub 隱私權聲明](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)。

本網站使用的字型、圖片、影片與搜尋索引均由本網站自行提供，瀏覽一般頁面時不會從其他網站載入字型或追蹤程式。送出線上詢問表單時，您的瀏覽器會連線至 Google，詳見第二節。

## 六、外部影片與連結

部分最新消息附有 YouTube 或 Facebook 影片。本網站只顯示前往該平台的一般連結；點選後即離開本網站，由該平台依其隱私權政策處理您的資料。

如日後有影片經核准以嵌入播放器方式呈現，播放器只會在您按下「載入播放器」後才載入（YouTube 使用 youtube-nocookie.com 網域）；載入後，該平台可能依其政策蒐集您的資料。

頁尾地址連結會在新分頁開啟 Google 地圖，同樣適用 Google 的隱私權政策。

## 七、網站內容管理後台

本網站的 /admin/ 路徑是供本公司授權管理人員編輯網站內容的工具（Sveltia CMS），不提供一般訪客使用，且不會被搜尋引擎收錄。管理人員以自己的 GitHub 帳號與個人存取權杖登入，權杖由管理人員自行在其瀏覽器中輸入並保存在該瀏覽器，由瀏覽器直接與 GitHub 通訊，本公司不另外設置伺服器接收或保存。開啟 /admin/ 時，瀏覽器會從 jsDelivr 內容傳遞網路下載 Sveltia CMS 程式。

4. 請求停止蒐集、處理或利用。

## 九、資料安全

本網站以 HTTPS 傳輸資料，詢問資料以 Google 試算表保存。資料存取應限於處理詢問所需的授權人員，並依工作需要管理權限。收件程式包含欄位驗證、重複送出檢查與試算表公式注入防護。表單內容不寫入瀏覽器的 localStorage；網站程式庫不保存管理員 Token 或 Google 私密憑證。雲端服務與電子郵件傳輸仍受各服務供應商的安全措施與使用條件約束。
