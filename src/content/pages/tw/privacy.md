本網站是靜態網站，頁面不設會員帳號，也不在您的瀏覽器設定 Cookie、localStorage 或其他追蹤識別碼。除您自行在「聯絡 BXR」頁面填寫並送出的線上詢問表單（第二節），本網站不蒐集您的個人資料。本網站目前未使用 Google Analytics 或其他網站分析、廣告追蹤工具。

## 四、站內搜尋

本網站的站內搜尋使用 Pagefind。搜尋索引在網站建置時產生並與網站一起發布，搜尋是在您的瀏覽器內比對該索引完成，您輸入的關鍵字不會傳送給本公司或其他搜尋服務。為了方便重新整理或分享，關鍵字會顯示在該頁網址中（例如 `?q=關鍵字`）。

## 五、網站主機與存取紀錄

本網站託管於 GitHub Pages（GitHub, Inc.，位於美國）。當您瀏覽本網站時，您的瀏覽器會直接向 GitHub 的伺服器要求網頁，GitHub 可能為維護服務安全與運作而記錄您的 IP 位址等存取資訊。這些紀錄由 GitHub 依其隱私權聲明處理；本公司未取得、也未使用這些存取紀錄。[待確認]

本網站使用的字型、圖片、影片與搜尋索引均由本網站自行提供，瀏覽一般頁面時不會從其他網站載入字型或追蹤程式。送出線上詢問表單時，您的瀏覽器會連線至 Google，詳見第二節。

## 六、外部影片與連結

部分最新消息附有 YouTube 或 Facebook 影片。本網站只顯示前往該平台的一般連結；點選後即離開本網站，由該平台依其隱私權政策處理您的資料。

如日後有影片經核准以嵌入播放器方式呈現，播放器只會在您按下「載入播放器」後才載入（YouTube 使用 youtube-nocookie.com 網域）；載入後，該平台可能依其政策蒐集您的資料。

頁尾地址連結會在新分頁開啟 Google 地圖，同樣適用 Google 的隱私權政策。

## 七、網站內容管理後台

本網站的 /admin/ 路徑是供本公司授權管理人員編輯網站內容的工具（Sveltia CMS），不提供一般訪客使用，且不會被搜尋引擎收錄。管理人員以自己的 GitHub 帳號與個人存取權杖登入，權杖由管理人員自行在其瀏覽器中輸入並保存在該瀏覽器，由瀏覽器直接與 GitHub 通訊，本公司不另外設置伺服器接收或保存。開啟 /admin/ 時，瀏覽器會從 jsDelivr 內容傳遞網路下載 Sveltia CMS 程式。

## 九、資料安全

本公司訂有資訊安全政策，以確保所保有資訊的機密性、完整性及可用性，避免遭受內、外部蓄意或意外的威脅。與您的個人資料相關的主要措施如下：

- 個人資料僅限因業務需要的授權人員存取，避免未經授權的存取與修改。
- 定期辦理資訊安全教育訓練，強化人員保護資料的意識與責任。
- 定期進行內部與外部稽核，確認各項安全作業確實執行。
- 所有人員均有責任通報資訊安全事件與已發現的弱點；危及資訊安全的行為，將依情節追究法律責任或依本公司規定懲處。
- 資訊安全政策由管理階層核定，並至少每年審查一次。
