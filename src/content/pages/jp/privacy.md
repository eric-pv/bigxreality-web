全球動力科技股份有限公司（以下「当社」）は、Big x Reality 公式ウェブサイト（以下「本サイト」）を運営しています。当社は台湾の「個人資料保護法」（以下「個資法」）および関連法令に基づき、本サイトにおける個人情報の取得、処理および利用について説明します。本ポリシーは本サイトにのみ適用され、本サイトのリンク先の他サイトには、各サイトのプライバシーポリシーが適用されます。

## 一、本サイトが取得しない情報

本サイトは静的なウェブサイトであり、会員アカウントはなく、お使いのブラウザに Cookie、localStorage その他の追跡用識別子を設定しません。「お問い合わせ」ページでお客様がご自身で入力・送信するオンラインお問い合わせフォーム（第二項）を除き、本サイトはお客様の個人情報を取得しません。

## 二、オンラインお問い合わせフォーム

「お問い合わせ」ページにはオンラインお問い合わせフォームがあります。フォームの下部に「同意して送信」と「同意しない」の二つのボタンがあり、「同意して送信」を押すと本ポリシーに同意したものとみなされ、フォームが送信されます。「同意しない」を押した場合、または送信するまでの間は、入力内容が当社に送られることはなく、ブラウザに保存されることもありません。

**取得する情報**

- お客様が入力する情報：お名前、会社・所属、メールアドレス（以上必須）、役職、国・地域、電話番号（以上任意）、お問い合わせ内容、関連する製品またはソリューション、ご相談内容。
- 送信時にあわせて記録する情報：送信日時、フォームを送信したページのパスと言語、システムが発行する受付番号、同意いただいたプライバシーポリシーの版。当社の受信プログラムはお客様の IP アドレスを記録しません。

**処理方法**：フォームはお客様のブラウザから、当社が Google Apps Script で構築した受信プログラムへ直接送信され、当社の Google スプレッドシートに保存されます。アクセスできるのは当社の権限を持つ担当者のみです。Google のクラウドサービスは Google LLC（米国）が提供しており、データは Google のデータセンターが所在する国または地域に保存される場合があります。送信時、お客様のブラウザは Google のサーバー（script.google.com、script.googleusercontent.com）に接続し、Google が同社のプライバシーポリシーに従って接続情報を記録する場合があります。[待確認] 新しいお問い合わせのメール通知を有効にするかどうか（有効にする場合、お問い合わせ内容は当社のメールアドレスにも送信されます）。

**利用目的**：お問い合わせへの回答、製品デモおよび資料のご提供、協業のご相談、ならびにその後の顧客サービスのため（特定目的：〇九〇 消費者・顧客管理およびサービス。[待確認] 特定目的コードは法務が確認）。

**利用期間**：[待確認] お問い合わせ情報の保存期間（例：回答完了後 N 年間、またはお客様から削除のご請求があるまで）。

**利用地域**：台湾（中華民国）国内、および Google のクラウドサービスがデータを処理する地域。

**利用者および利用方法**：当社の営業担当およびカスタマーサービス担当が、メール、電話などでご回答・ご連絡します。法令に基づく場合またはお客様の同意がある場合を除き、第三者に提供しません。[待確認] 販売代理店またはパートナーへお問い合わせを引き継ぐ場合があるかどうか。

必須項目が未入力の場合、または本ポリシーに同意いただけない場合、フォームは送信されません。その場合も、第三項のメールにてお問い合わせいただけます。

## 三、メールでのお問い合わせ

本サイトの「お問い合わせ」ページおよびフッターには、メールアドレス（service@gptt.com.tw）へのリンクがあります。選択するとお使いの端末のメールソフトが開き、件名と次の記入項目（お名前、会社・所属、役職、国・地域、電話番号、ご相談内容）があらかじめ入力されます。メールを送信するかどうか、何を記入するかはお客様の判断によるもので、本サイト自体がこれらの内容を受信・保存することはありません。

メールを送信いただいた場合、当社は次の情報を取得します。

- お客様のメールアドレス、およびメールに記載された情報（お名前、会社・所属、役職、国・地域、電話番号、ご相談内容など）。
- お使いのメールサービスが自動的に付加するヘッダー情報。

**利用目的**：お問い合わせへの回答、製品デモおよび資料のご提供、協業のご相談、ならびにその後の顧客サービスのため（特定目的：〇九〇 消費者・顧客管理およびサービス。[待確認] 特定目的コードは法務が確認）。

**利用期間**：[待確認] お問い合わせメールの保存期間（例：回答完了後 N 年間、またはお客様から削除のご請求があるまで）。

**利用地域**：台湾（中華民国）国内、および当社のメールサービス提供事業者がデータを処理する地域（[待確認] メールサービス提供事業者名およびデータ保存地域）。

**利用者および利用方法**：当社の営業担当およびカスタマーサービス担当が、メール、電話などでご回答・ご連絡します。法令に基づく場合またはお客様の同意がある場合を除き、第三者に提供しません。[待確認] 販売代理店またはパートナーへお問い合わせを引き継ぐ場合があるかどうか。

上記の情報をご提供いただかないこともできますが、その場合、お問い合わせへの回答や必要な資料のご提供ができないことがあります。

## 四、サイト内検索

本サイトのサイト内検索には Pagefind を使用しています。検索インデックスは本サイトの構築時に生成されて本サイトと一緒に公開され、検索はお客様のブラウザ内でこのインデックスと照合して行われます。入力したキーワードが当社やその他の検索サービスに送信されることはありません。再読み込みや共有の便宜のため、キーワードはページの URL に表示されます（例：`?q=キーワード`）。

## 五、ホスティングとアクセスログ

本サイトは GitHub Pages（GitHub, Inc.、米国）でホスティングされています。本サイトを閲覧すると、お客様のブラウザは GitHub のサーバーに直接ページを要求し、GitHub はサービスの安全と運用のために IP アドレスなどのアクセス情報を記録する場合があります。これらの記録は GitHub のプライバシーに関する声明に従って取り扱われ、当社が取得または利用することはありません。[待確認]

本サイトで使用するフォント、画像、動画および検索インデックスはすべて本サイトから提供しており、通常のページ閲覧時に他のサイトからフォントや追跡用プログラムを読み込むことはありません。オンラインお問い合わせフォームを送信する際は、第二項のとおりお客様のブラウザが Google に接続します。

## 六、外部動画とリンク

一部のニュース記事には YouTube または Facebook の動画が含まれます。本サイトではこれらのプラットフォームへの通常のリンクのみを表示しており、選択すると本サイトを離れ、各プラットフォームのプライバシーポリシーに従って情報が取り扱われます。

今後、埋め込みプレーヤーでの表示が承認された動画がある場合、プレーヤーは「プレーヤーを読み込む」を押した後にのみ読み込まれます（YouTube は youtube-nocookie.com ドメインを使用）。読み込み後は、各プラットフォームがそのポリシーに従って情報を取得する場合があります。

フッターの住所リンクは新しいタブで Google マップを開き、同様に Google のプライバシーポリシーが適用されます。

## 七、ウェブサイト管理画面

本サイトの /admin/ は、当社の権限を持つ担当者がサイトの内容を編集するためのツール（Sveltia CMS）であり、一般の訪問者向けではなく、検索エンジンにも登録されません。担当者は自身の GitHub アカウントと個人用アクセストークンでログインし、トークンは担当者が自身のブラウザに入力・保存して、ブラウザから GitHub と直接通信します。当社がトークンを受信・保存するサーバーを別途設置することはありません。/admin/ を開くと、ブラウザは jsDelivr のコンテンツ配信ネットワークから Sveltia CMS のプログラムをダウンロードします。

## 八、お客様の権利

当社が保有するお客様の個人情報について、お客様は個資法第三条に基づき、次の権利を行使できます。

1. 照会または閲覧の請求
2. 複製物の交付の請求
3. 補充または訂正の請求
4. 取得、処理または利用の停止の請求
5. 削除の請求

ご請求は service@gptt.com.tw までメールでお送りください。ご本人であることを確認のうえ、個資法に定める期間内に対応いたします。個資法第十四条に基づき、照会、閲覧または複製物の交付については、必要な実費をいただく場合があります（[待確認] 手数料の有無）。

## 九、情報セキュリティ

当社は情報セキュリティポリシーを定め、保有する情報の機密性、完全性および可用性を確保し、社内外からの故意または偶発的な脅威から保護しています。お客様の個人情報に関する主な取り組みは次のとおりです。

- 個人情報には、業務上必要な権限を持つ担当者のみがアクセスでき、権限のないアクセスや改ざんを防止しています。
- 情報セキュリティ教育を定期的に実施し、データ保護に関する担当者の意識と責任を強化しています。
- 内部監査および外部監査を定期的に実施し、セキュリティ対策が確実に実施されていることを確認しています。
- すべての担当者は、情報セキュリティ事故および発見した脆弱性を報告する責任を負います。情報セキュリティを脅かす行為については、その程度に応じて法的責任を追及し、または当社の規定に基づき処分します。
- 情報セキュリティポリシーは経営陣が承認し、少なくとも年に一度見直しています。
