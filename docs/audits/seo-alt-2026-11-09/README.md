# 全站 SEO、關鍵字主題與 alt 檢查

日期：2026-11-09（台北）。以 main `afd1c4f` 建立獨立分支，檢查正式內容的本機建置。這不是 Google 收錄／排名或線上部署的證明。

## 結論

SEO 基本欄位與技術設定完整，商業頁已有可辨識的主題分工，但不能因此宣稱關鍵字研究與內容優化全部完成。本次把逐頁資料、圖片使用位置與主題分工整理成可核對的清單，並修正確認有誤的替代文字。

Title、Description、Canonical、hreflang、OG／Twitter、JSON-LD、單一 H1、標題層級、sitemap 與 robots 已由 `qa:seo` 覆蓋全部 294 頁。

90 個 noindex：75 個新聞分類／年份篩選頁；案例、投資人、技術專欄、搜尋、標籤索引各 3 頁。這些是既有空內容或工具／篩選頁政策，不當成漏做 SEO，也不擅自開放索引。

87 個商業頁的主要主題均出現在現有 SEO 標題中。其餘 117 頁以新聞事件或資訊用途為焦點，不強塞產品詞；90 個 noindex 頁不配置自然搜尋目標。CSV 的字面命中只是診斷，不能據此要求每個 H1、Description 與 alt 都重複相同詞句。

網站沒有 `meta keywords`，這是正確狀態：Google 不使用該欄位決定排名。本次沒有新增它，也沒有擴充 CMS 欄位。

## 已修正

1. **掃描器漏頁**：舊 `qa:seo` 在任意深度排除名為 `media` 的目錄，誤跳過 18 個新聞 media 分類頁，只有檢查 276 頁。現在只排除根目錄的靜態資產資料夾；重跑覆蓋完整 294 頁，0 錯誤。
2. **SUT 三語 alt**：圖片實際是四名學員在展示舞台演練，原文字卻寫成「站在載具模擬器前」。修正 3 個來源欄位，影響 39 個圖片實例。
3. **迫擊砲三語 alt**：實際照片是兩名人員在展示舞台操作設備，原文字卻描述「模擬戰場中的觀測射擊訓練」。修正 3 個來源欄位，影響 3 個圖片實例。

人工對照 32 張產品／解決方案原始圖與首頁影片封面，共 33 個內容影像。機構與品牌 Logo 依現有核准名稱核對；沒有變更原圖、圖片位置、分類／核准狀態、產品事實或正文，也沒有改寫已核准的 SEO 標題與描述。修正尚須經 PR／CI／部署才會影響線上網站。

## 還需要改善的地方

### 1. 部分 alt 太籠統

97 個實例使用「代表畫面／representative image／紹介画像」等用詞。這不是缺少 alt，但對讀屏使用者的資訊有限。例如 UAV 圖實際是第一人稱反制無人機射擊模擬畫面，滅火器圖是 VR 操作人員與火焰的合成圖；可改成具體畫面描述，不宜只是產品關鍵字。

231 個空 alt 已確認為 213 個帶鄰近文字的產業圖示，以及 18 個 `aria-hidden` 的技術列表裝飾縮圖，應保留空值。不要為了 SEO 補成重複或冗長的文字。

27 個機構 Logo 的英、日文 alt 目前沿用已核准的中文正式名稱，資料也標記英日審核完成。它們有名稱，不是漏填；若日後要在地化，應核對官方譯名，不自行發明機構名稱。

### 2. 搜尋摘要仍有優化空間

- 三語 CSR 的 Description 直接沿用一句理念標語，缺少具體 CSR 內容摘要；建議增加獨立 SEO 描述，不改版面上的 lead。草稿見 [PROPOSALS.md](PROPOSALS.md)。
- 42 個英文可索引頁的完整 Title 超過 70 字元；41 個英文可索引頁的 Description 超過 200 字元。清單及長度已在 CSV／JSON。這是優先檢視名單，不代表 Google 一定截斷或扣分：實際顯示受字寬、裝置、查詢與搜尋引擎改寫影響。精簡時保留產品名、展會、年份與限制，不機械裁字。
- 123 個可索引頁仍用 `icon-512.png` 作 OG 品牌備援（99 個新聞／列表頁、12 個公司頁、聯絡與政策各 3、解決方案與技術各 3）。標籤並未缺漏，但分享卡片辨識度有限；需核准封面或正式品牌分享圖才能改善。

### 3. 尚無實際搜尋成效資料

本次沒有 Search Console、搜尋量、排名、競品或詢問轉換資料。主題分工是依現有內容核對，尚不能證明選字符合市場需求、已被 Google 收錄或沒有查詢層面的關鍵字互搶。

技術專欄與案例尚無正式文章，部分比較、導入條件與案例證據等需求沒有專門內容承接。這些是內容／資料工作，不能用補 meta 標籤或虛構案例替代。
