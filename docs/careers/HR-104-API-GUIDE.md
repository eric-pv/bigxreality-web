# 人資操作說明：申請 104「人力銀行 Open API」

目的：讓官網「關於 BXR」頁每月自動顯示公司在 104 的公開職缺。人資之後只要照常在 104 維護職缺，官網會自己更新。

## 1. 聯絡 104

優先找公司現有的 104 業務窗口；沒有窗口就用 104 人資學院的[聯絡我們](https://ehr.104.com.tw/Contactus.html)。

可以直接這樣寫：

> 您好，我們是全球動力科技股份有限公司（統編：＿＿＿＿，104 公司頁：https://www.104.com.tw/company/1a2x6bjhcz）。
> 我們想在公司官網顯示本公司在 104 的公開職缺，並連回 104 職務頁讓求職者應徵。
> 想申請「人力銀行 Open API」（Job Search API，scope：c_job）的 client_id 與 client_secret，請問：
> 1. 本公司是否符合申請資格？需要什麼文件？
> 2. 是否收費？費用多少？
> 3. 使用條款是否允許在自家官網列出職缺並連回 104？
> 4. 呼叫次數有無限制？（我們每月只會查詢一次）

## 2. 注意：只申請這一項

- **要申請：** 人力銀行 Open API（scope `c_job`），只用來讀取公開職缺。
- **不要申請：** 履歷相關 API（Resume API）、Job API（刊登職缺用）。官網不需要也不會讀取履歷或應徵者資料。

## 3. 收到之後

104 會用信件寄出 **ID（client_id）** 和 **Secret（client_secret）**，有時是加密附件（密碼可能是公司統編）。

- 交給業主（Eric）即可，由業主設定到 GitHub。
- **不要**用 Line、一般群組、Email 轉寄給其他人，也不要貼到文件或對話視窗。Secret 等同密碼。
- 同時回報 104 回覆的費用與使用條款。

## 4. 之後的維護

人資只需要在 104 新增、修改、關閉職缺。官網每月 1 日自動同步一次；急著更新時，請業主手動執行一次同步。
