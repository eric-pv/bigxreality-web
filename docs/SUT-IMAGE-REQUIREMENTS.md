# SUT 產品頁圖片素材需求清單

2026-11-11：依業主確認的新文案順序更新。頁面先介紹操作熟悉度、CQB 與多人協同，再呈現訓練模組、訓後檢討與跨產品搭配。

網址：`/tw/products/sut/`。目前預留 7 個圖片位置；未提供素材的位置不顯示空白框。Hero 沿用現有核准實拍照，其餘等待業主整理 flyer 圖片。

## 通用規格

- 圖片比例依 [全站版面原則](LAYOUT-RULES.md)：產品頁統一 16:9 填滿顯示；提供原始檔，不必先裁切。
- JPG／PNG，建議寬度至少 1600 px。原始媒體不覆蓋、不壓縮或裁切，以新檔名匯入。
- 重要人物、設備與介面文字保留裁切餘裕。軟體截圖盡量提供未經 flyer 排版的原圖，避免小字與多畫面拼圖縮小後難以閱讀。
- 只使用已核准的 SUT 實拍、實際軟體畫面或實機錄影截圖；不將示意圖當成實機功能證據。
- 圖片在三語使用相同來源，各語分別提供替代文字與必要圖說。照片中的單位、人物與資訊須可公開。

## 預留位置

| # | 位置與欄位 | 建議畫面 |
| --- | --- | --- |
| 1 | 首屏 `landing.heroImage`；未指定時沿用 `hero.image` | 多名學員使用 SUT 共同演練的全景實拍；目前現有實拍照保留 |
| 2 | CQB／多人協同 `landing.approach.images[0]` | 學員操作擬真訓練槍械與穿戴設備的實拍 |
| 3 | CQB／多人協同 `landing.approach.images[1]` | 與實拍對應的實際虛擬情境或多人共同演練畫面 |
| 4 | 射擊單元 `landing.capabilities.items[0].image` | 定點、多重目標、障礙板後方射擊，或環形／移動人形／旋轉靶；挑清楚的代表畫面 |
| 5 | CQB／據點攻堅 `landing.capabilities.items[1].image` | 室內戰鬥或犯罪據點攻堅的實際系統畫面 |
| 6 | 戰場／多人演練 `landing.capabilities.items[2].image` | 戰場模擬、掩體與多人協同畫面；沙包若為虛擬場景，不描述成實體設施 |
| 7 | 模式／武器轉換 `landing.capabilities.items[3].image` | 訓練／測驗模式或長短槍轉換的實際畫面；器材依配置說明 |

Flyer 的各種射擊單元都已列入文案，不需要把每張靶圖都塞進同一頁。收到圖片後，依畫面清晰度與段落用途挑選；同一單元若需多張圖，再討論使用既有支援的圖片欄位。

## 其他圖片

- 教官多視角介面、彈著／命中資訊與訓後報告：可以提供，之後視內容配置到訓練檢討步驟的既有可選 `image` 欄位。
- UAV／USV 的關聯卡片沿用各產品圖片。跨系統功能只描述已確認的連接方式，不以圖片推定互通能力。
- 不再要求「AI 隨表現自動調整敵我行為」或「XR 顯示隊友狀態」圖片；目前 flyer 未確認這些功能。

## 填入方式

1. 原始圖片以新檔名存放 `src/assets/images/products/`，建議以 `sut-` 開頭。
2. 在三語 `src/content/products/<zh-Hant|en|ja>/sut.md` 相同位置填入相同 `src`，各語分別填寫 `alt`；保留 `need` 與 `ratio: 16 / 9`。
3. 未指定 `src` 的位置不公開顯示。上傳媒體後仍須指派到對應欄位，才會出現在前台。
4. Sveltia 使用既有產品「落地頁」欄位；不手改產生的 CMS 設定檔。
