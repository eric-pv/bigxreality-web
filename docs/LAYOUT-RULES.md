# BXR 版面原則

日期：2026-11-04（台北）。依業主指示訂定，適用全站所有頁面（首頁、產品、解決方案、技術、案例、新聞內頁、公司頁）。新增或修改元件時須遵守，不得在個別頁面另訂不同排法。

## 1. 並排項目的排數

區塊內並排的卡片、步驟、特色、數據等，依「項目數量」決定每排幾個：

| 項目數 | 桌機排法 |
| --- | --- |
| 1 | 單張置中（最寬 640px） |
| 2 | 一排 2 個 |
| 3 | 一排 3 個（同一排） |
| 4 | 上 2 下 2 |
| 5 | 上 3 下 2 |
| 6 以上 | 每排 3 個；最後一排不滿時置中，卡片寬度不變 |

- 平板（768–1023px）每排最多 2 個；手機（767px 以下）每排 1 個。
- 實作：在清單容器加上共用 class `balanced`（`src/styles/global.css`），由項目數自動決定排法；需要在程式中判斷時使用 `src/lib/layout.ts` 的 `perRow()`／`endsRow()`。元件不得再自行寫死 `grid-template-columns: repeat(4, …)` 之類的欄數。
- 訓練流程（`FlowSteps`）同樣依此規則分排，例如 5 個步驟為上 3 下 2；連接虛線在每排最後一個步驟結束，不跨到下一排。流程的最後一排靠左，維持由左到右的閱讀順序。
- 內頁的關聯內容卡片（相關產品、解決方案、技術文章、案例）使用 `SmartCardGrid` 元件：卡片固定為桌機三欄寬度，2 張不放大、置中；7 張為 3＋2＋2、10 張為 3＋3＋2＋2，最後一排不留單張。首頁不使用。
- 內頁「左側章節標題、右側內容」的分欄使用 `SplitSection`：桌機時標題整組相對右側內容垂直置中（`align="start"` 供導覽、篩選等功能欄靠上）；堆疊時恢復靠上。
- 不適用：分頁列表（新聞、文章、產品總覽、標籤頁）、客戶 Logo 牆、頁尾選單及統計數字列。這些依各自的列表版型排列。

## 2. 手機與平板的圖文排版

桌機的圖文列可以左右交錯；一旦變成上下堆疊（平板與手機），一律：

1. **文字在上，圖片在下。** 標題與說明先出現，對應的圖片緊接在文字下方，全站不得有的頁面圖在上、有的頁面圖在下。
2. **同一組圖文放在同一張卡片裡**，以底色（白底）、細框與頂部粗線和下一組區隔，讓讀者清楚知道這張圖屬於上方的文字。
3. 組與組之間保留明顯間距，不讓圖片看起來屬於下一段文字。

目前套用的元件：

| 元件 | 用途 |
| --- | --- |
| `CapabilityShowcase` | 核心訓練應用／主要應用領域的圖文列 |
| `ScenarioCards` | 應用情境卡片（手機版文字在上、圖片在下） |
| `FlowSteps` | 含圖片的流程步驟（圖片移到文字下方並加底色卡片） |
| 介紹段落圖片（`introImage`）、解決方式圖片 | 本來就是文字在上、圖片在下 |

新增任何「圖片＋文字」元件時，手機版須符合本節三點。

## 3. 圖片比例

解決方案與產品落地頁的內容圖片位置統一 16:9（`ratio: 16 / 9`）。網站以填滿裁切顯示，不另外重製圖片檔。

器材照片與需要辨識標籤的軟體介面，可使用 `fit: contain`：外框仍維持 16:9，原圖完整置中並提供「放大檢視」。此方式用於保留設備、標籤與操作結果，避免裁掉重要資訊；一般情境照片仍沿用填滿裁切。2026-11-11 滅火器頁重新整理時採用。

## 4. 三語文字與換行

- 先讓句意自然、文字精簡，再安排版面。不得為了行長強制插入 `<br>`、不換行空白，或把一般詞彙包成不可拆的區塊。
- 中文與日文遵循語言的標點禁則；英文依完整單字換行，不任意切開單字。極長網址等超出容器時才允許緊急折行。
- 詞庫與標題分組只能作為行內語意標記，不得形成 `inline-block` 盒子，將助詞、連詞或標點擠到不自然的位置。
- 標題及短篇中日文說明使用瀏覽器的平衡換行；長文仍以自然段落閱讀。已知尺寸出現末行僅一至二個中文字／日文字時，精簡原文並重新檢查手機、平板與桌機；不得用縮字級、加空白或截掉內容掩飾。
- 文案精簡保留名稱、日期、數字、規格與功能限制；法定告知保留內容，以完整語意分段。
- `npm run qa:typography` 量測全部公開三語頁面在 320、375、390、430、768、1024、1440px 的實際文字行。末行孤字、行首禁則標點、英文單字截斷及橫向溢出都是驗收失敗，並輸出可定位的清單。自動量測之外仍需人工檢視三語畫面及句意。
